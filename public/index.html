How it works

The big screen runs the game. Each phone opens a controller page in the browser — nothing to download.

01
Pick a game
Open Shared Couch on a TV, laptop or tablet, choose a game and press Create Game.
02
Scan the QR
Each player scans the code with their phone camera. The controller opens in Chrome or the default browser.
03
Tap Ready and play
When every player is ready, the round starts. Some games, like Counting Clash and Rock Drift, also work solo.

About Shared Couch

Shared Couch brings back the feeling of playing side by side — without consoles or extra controllers. One screen hosts the game, and everyone in the room plays with the phone already in their pocket.

Every game is built for the same quick loop: open, scan, ready, play. Short rounds, simple controls, and a shared screen to shout at.
